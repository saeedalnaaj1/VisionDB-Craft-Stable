# License handling

The supplied project includes an MIT license with copyright 2026 Saeed Sameeh Abualnaaj. It is preserved verbatim. The rebrand does not alter its terms or invent a license for either edition.

Dependency code and model checkpoints have their own licenses. Models are downloaded explicitly, stored outside the executable and never redistributed in these source ZIPs. Plus retains the model catalog's upstream license/source notices; they are not blanket permission for commercial checkpoint redistribution.

A frozen release must retain all third-party notices supplied by its resolved dependencies, including Python, OpenCV, NumPy, pywebview and, for Plus, the ML runtimes. The current delivery consists of source packages and contains no bundled third-party runtime binaries. Windows release maintainers must collect dependency notices and check checkpoint/data terms before publication. Do not describe a dependency/model license review as complete based on this file.
